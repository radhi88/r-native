# نظام البحث عن استراتيجيات التداول — ملخّص المشروع والمحادثة

## نظرة عامة
نظام يكتشف استراتيجيات التداول من **الويب (مقالات)** و**الفيديو (صوت + صورة)** بشكل
مستمر، يستخرجها كمواصفات دقيقة، يحوّلها إلى صيغة قابلة للباكتست (MQL5 / باراميترات)،
ويربطها بنظام التداول الرئيسي (MT5 + نظام الـ DNA). الهدف أتمتة الدورة:
**اكتشاف ← استخراج ← ترميز ← باكتست ← إطلاق** بدل المراقبة والرسم والهندسة اليدوية.

## رحلة المحادثة (ملخّص)
1. البداية: طلب تحليل فيديوهات إنستقرام واستخراج الاستراتيجيات.
2. توضيح القيود: لا يمكن "مشاهدة" فيديو من رابط؛ الفهم يتطلب جلب إطارات + تفريغ صوت؛
   وإنستقرام يحظر الوصول الآلي. الحل: pipeline محلي.
3. بناء محلّل المحتوى، ثم وكيل `study_account.py` يتصفّح الحساب ويمسح كل فيديو بعد فهمه.
4. توحيد الفكرة مع نظام الـ DNA: جينات + تطوّر (crossover/mutation) + وكلاء (Arena) +
   حلقة تغذية راجعة.
5. **التحوّل الجوهري:** ليست فيديوهات تسويقية — بل **استراتيجيات تداول**. الـ fitness =
   نتيجة الباكتست الحقيقية (P&L) مو التفاعل (لايكات/مشاهدات أُسقطت).
6. إعادة بناء المحلّل لاستخراج استراتيجية تداول + توليد MQL5، مع جعل الباراميترات
   الناقصة في الفيديو = **جينات التحسين** التي يبحث عنها الباكتست.
7. الرؤية الكاملة: نظام باحث **مستمر** و**متعدد المصادر** (نص + فيديو) **مرتبط بنظام
   التداول** ← بناء `scout.py` + `extract_web.py`.

## المعمارية النهائية (٦ طبقات)
1. **اكتشاف** (مستمر): Claude + web_search يجد مصادر جديدة (مقال/فيديو).
2. **استخراج**: المقال ← `extract_web.py`؛ الفيديو ← `analyze_strategy.py`. الاثنان
   يطلّعان نفس الـ spec.
3. **ترميز**: spec ← MQL5 EA / باراميترات.
4. **جسر الباكتست**: يدخل MT5/DNA، و`OnTester()` يكتب fitness في `gold_dna_memory.csv`.
5. **بوابة + إطلاق**: ترتيب الفائزين، موافقة بشرية، ثم الإطلاق.
6. **المنسّق `scout.py`**: اللوب الدائم + registry يربط ١–٥، يشتغل على جهازك (نفس فكرة
   `ea_monitor.py`) وClaude API هو العقل.

## الملفات

### وضع التداول (الغرض الحالي)
| ملف | الدور |
|-----|-------|
| `scout.py` | المنسّق المستمر: اكتشاف + توجيه نص/فيديو + registry + hooks للباكتست/الإطلاق |
| `analyze_strategy.py` | فيديو تداول ← strategy spec + MQL5 EA + خريطة باراميترات |
| `extract_web.py` | مصدر مكتوب (رابط/نص) ← نفس الـ spec |
| `README_STRATEGY.md` | دليل وضع التداول + scout |

### مشترك
| ملف | الدور |
|-----|-------|
| `analyze_reels.py` | الإطارات + تفريغ Whisper + استدعاء Claude (يُعاد استخدامه) |
| `download_reels.py` | تنزيل فيديوهات حساب (instaloader) |
| `requirements.txt` | الاعتماديات |

### وضع المحتوى (من المرحلة الأولى — اختياري)
| ملف | الدور |
|-----|-------|
| `study_account.py` | وكيل يتصفّح حساب، يفهم كل ريل ويمسحه، ثم playbook |
| `dna_schema.py` | backbone الجينات/التطوّر/الـ CSV |
| `export_dna.py` · `evolve.py` · `arena.py` · `log_result.py` | جينات المحتوى + تطوّر + Arena + حلقة |
| `StrategyFeed.jsx` | عرض النتائج في React Native |
| `README.md` | دليل وضع المحتوى |

## التشغيل (وضع التداول)
```bash
pip install -r requirements.txt
set ANTHROPIC_API_KEY=sk-ant-...

# دفعة يدوية على فيديوهات موجودة
python download_reels.py SOME_TRADER --out ./videos --login YOUR_USERNAME --limit 20
python analyze_strategy.py --videos ./videos --out ./strategies

# مصدر مكتوب
python extract_web.py --url https://site.com/article --out ./strategies

# النظام المستمر
python scout.py --once      # دورة اختبارية
python scout.py             # تشغيل دائم
```

## المتبقّي (الوصلة الأخيرة لنظامك)
ثلاث معلومات من بيئتك لإقفال الحلقة (تحويل `backtest_hook`/`deploy_gate` من TODO إلى فعلي):
1. أعمدة `gold_dna_memory.csv` بالترتيب الدقيق.
2. كيفية تشغيل الباكتست/الـ optimization حالياً (MetaEditor/MT5 CLI؟ config؟ يدوي؟).
3. بوابة الإطلاق: موافقة يدوية دائماً، أم شروط آلية (profit factor / drawdown) ثم تنبيه.

## ملاحظات صادقة
- اللوب يشتغل على جهازك، مو داخل الشات.
- المصادر الموثوقة للاستمرارية: مقالات الويب + YouTube. إنستقرام يحظر الأتمتة.
- ملفات الـ `.mq5` المولّدة **سكربتات جاهزة للباكتست، مو EA نهائي** — راجعها وطابق أعمدة
  `OnTester()` مع سكيمتك.
- الباراميترات الغامضة في الفيديو تُترك ضمن `to_optimize` ليجد الباكتست قيمها.
- **بوابة موافقة بشرية قبل التداول الحي** مقصودة — لا إطلاق تلقائي على فلوس حقيقية.
