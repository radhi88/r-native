# 00 Inbox — Capture First, Think Later

## The Rule
**Never think while capturing. Sort later.**

When an idea, link, insight, quote, or task hits you — drop it here immediately as a raw note. No formatting, no categorizing, no perfect titles. The only job of the Inbox is to make capture frictionless so nothing is ever lost.

- Capture in seconds: one thought = one note (or one line in a daily dump note).
- Do NOT decide where it belongs yet. Deciding kills the capture habit.
- Do NOT polish. Raw and ugly is fine here.

## القاعدة بالعربي
**لا تفكر أثناء الالتقاط — التقط الآن، رتّب لاحقًا.**
أي فكرة أو رابط أو خاطرة: ارمها هنا فورًا كما هي. الفرز والربط والتصنيف وقتُه لاحقًا في جلسة الفرز اليومية (10 دقائق)، وليس لحظة الالتقاط.

## Daily Sort (part of the 10-minute workflow)
Once a day, empty this folder:
1. Open each note.
2. Move it to its real home ("01 Prompts", "02 Research", "03 Meeting Notes", "04 Customer Insights", "05 Product Ideas", "06 Internal Docs", "07 Workflows", "08 Decisions"...).
3. Apply the matching template from `[[11 Templates]]`.
4. Add `[[links]]` to related notes.

An empty Inbox at the end of the day means the system is working.
