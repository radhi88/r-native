عن النظام

العقل العميق — كيف يتعلّم

يقرأ كل رمز سائل في 6 فريمات (M5–D1) عبر كل المؤشرات + الزخم + التذبذب + المستويات + الجلسة + اتجاه HTF. لكل نداء عالي-الثقة يُسجّل النتيجة بعد 4 ساعات (بوحدات R) ويُراكمها على: خصائص مفردة، تركيبات كاملة، لكل رمز، ولكل اتجاه.

الصدق: t حقيقي بالانحراف المعياري (لا افتراض σ=1R) + نطاق ثقة 95% + تصحيح Bonferroni على كل الخلايا المُختبَرة — فلا يظهر «مرشّح مُثبت» إلا إذا صمد للدلالة بعد التصحيح (يمنع حافّة وهمية من كثرة الاختبار).

المعمار

نافذة أصلية (WebView2) + واجهة JS/SVG + خلفية Python/FastAPI فوق محرّكاتك. REST + WebSocket لحظي (~0.5ث). قراءة فقط للأرقام؛ التحكّم = تشغيل/إيقاف الأسطول. ديمو. لا توصيل لرصيد حقيقي قبل مرشّح مُثبت صامد.
